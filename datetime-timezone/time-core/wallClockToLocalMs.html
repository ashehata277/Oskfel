wallClockToLocalMs()

Packs a WallClock into one number by pretending it is UTC.

function wallClockToLocalMs(wall: WallClock): number

Description

Doing arithmetic on seven separate fields is awkward. This function packs the wall clock into a single number using Date.UTC. The number is not a real moment; it is "the wall clock read as if the zone were UTC". The engine calls this a local ms value. Subtracting the zone offset from it gives the real UTC moment.

Why it exists

Turns seven fields into one number so offsets can be added and subtracted.

  • The engine's core trick is "wall clock read as UTC, minus offset, equals the real moment". That needs the wall clock as a single number.
  • Date.UTC is used rather than new Date(y, m, d, ...) because the latter uses the device's zone.

Without it: Field-by-field arithmetic with manual carry over minutes, hours, days, months and leap years.

Step by step

  1. Call Date.UTC(year, month - 1, day, hour, minute, second, millisecond). The month is 1-based in WallClock and 0-based in Date.UTC.

Examples

These outputs were produced by running the real function.

wallClockToLocalMs({ year: 2026, month: 1, day: 15, hour: 12, minute: 0, second: 0, millisecond: 0 })
1768478400000

Good to know

  • The opposite direction is wallClockFromLocalMs.

Source

function wallClockToLocalMs(wall: WallClock): number {
  return Date.UTC(wall.year, wall.month - 1, wall.day, wall.hour, wall.minute, wall.second, wall.millisecond);
}
