offsetMsAt()

How far ahead of UTC (in ms) a zone's wall clock is at one exact moment.

function offsetMsAt(zone: ZoneId, epochMs: number): number

Description

This is the heart of the file. A zone's offset is not a constant: London is +0 in winter and +1 in summer. The function asks Intl what the wall clock reads in that zone at that moment, packs that reading into local ms, and subtracts the real moment. The difference is the offset in milliseconds.

Why it exists

A zone's offset changes with DST, so it must be looked up for each moment.

  • Offsets are not constants: London is +0 in winter and +1 in summer, and some countries have changed their rules over the years.
  • Intl does not expose the offset directly, but it does expose the wall clock. Wall clock minus real moment is the offset.
  • Every conversion in both directions relies on this one function, so DST handling lives in exactly one place.

Without it: A fixed offset per zone, which would be wrong by an hour for half the year.

Step by step

  1. Format the moment with wallClockFormatter(zone).formatToParts.
  2. Read each part as a number; take hour % 24 because some engines print midnight as 24.
  3. Pack the parts with Date.UTC (whole seconds only, since Intl drops milliseconds).
  4. Floor the input moment to whole seconds as well, then subtract. The result is the offset.

Examples

These outputs were produced by running the real function.

offsetMsAt("Africa/Cairo", Date.parse("2026-01-15T10:00:00Z"))
7200000
offsetMsAt("Europe/London", Date.parse("2026-07-15T10:00:00Z"))
3600000
offsetMsAt("Asia/Kolkata", Date.parse("2026-07-15T10:00:00Z"))
19800000

Good to know

  • Positive means east of Greenwich (Cairo +2h = 7,200,000). Negative means west (New York −5h).

Source

function offsetMsAt(zone: ZoneId, epochMs: number): number {
  const parts = wallClockFormatter(zone).formatToParts(new Date(epochMs));
  const read = (type: string): number => Number(parts.find((part) => part.type === type)?.value);
  const localMs = Date.UTC(
    read('year'),
    read('month') - 1,
    read('day'),
    read('hour') % 24,
    read('minute'),
    read('second'),
  );
  const flooredEpochMs = Math.floor(epochMs / MS_PER_SECOND) * MS_PER_SECOND;
  return localMs - flooredEpochMs;
}
