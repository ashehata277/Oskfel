parseCalendarDay()

Returns the string if it is a real "yyyy-MM-dd" day, otherwise null.

function parseCalendarDay(value: unknown): CalendarDay | null

Description

A validator for calendar days. The display code also uses it to tell the two kinds of value apart: if a value passes this check it is a calendar day and is shown as-is, never shifted by a zone; otherwise it is treated as an instant.

Why it exists

Validates calendar days, and tells calendar days apart from instants.

  • API and form values must be checked before use; 2026-02-29 is not a real day.
  • The display code uses it to decide how to show a value: a calendar day is never shifted by a zone, while an instant is.

Without it: A due date would be treated as midnight UTC and could show as the previous day for users west of UTC.

Step by step

  1. Non-strings → null.
  2. Must match exactly yyyy-MM-dd.
  3. Round-trip through Date.UTC to reject 29 February in non-leap years, 31 April, and so on.

Source

export function parseCalendarDay(value: unknown): CalendarDay | null {
  if (typeof value !== 'string') {
    return null;
  }
  const match = CALENDAR_DAY_PATTERN.exec(value);
  if (!match) {
    return null;
  }
  const [year, month, day] = match.slice(1, 4).map(Number);
  const roundTrip = new Date(Date.UTC(year, month - 1, day));
  const isRealDay =
    roundTrip.getUTCFullYear() === year && roundTrip.getUTCMonth() + 1 === month && roundTrip.getUTCDate() === day;
  return isRealDay ? value : null;
}
