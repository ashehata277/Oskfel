resolveTeamWallClock()

Team wall clock → UTC, with an honest report about DST gaps and overlaps.

function resolveTeamWallClock(input: WallClockInput, zone: ZoneId): ResolvedWallClock

Description

This is the "save" direction, and it is the hard one. Turning "09:00 in London" into UTC needs the offset, but the offset depends on the UTC moment we are still looking for. Daylight saving time adds two traps: some wall times never happen (a gap: London jumps from 01:00 to 02:00 in March), and some happen twice (an overlap: 01:30 happens twice in October). This function handles all three cases and says which one it hit.

Why it exists

Converting a typed time to UTC is ambiguous around DST, and those cases must be handled on purpose.

  • Going from wall clock to UTC needs the offset, but the offset depends on the UTC moment. This function resolves that loop safely.
  • On the spring-forward night some times never happen (London 01:30 on 29 March 2026). Picking the next real time is better than throwing at the user.
  • On the fall-back night some times happen twice. Choosing the first occurrence makes the result predictable.
  • It returns a status so tests (and any future UI warning) can tell valid, gap and ambiguous apart.

Without it: Saving at DST changes would be off by an hour, or would crash on times that do not exist.

Step by step

  1. Validate and complete the input with completeWallClock, then pack it into local ms.
  2. Read the offset 36 hours before and 36 hours after. Those are the only two offsets that can apply (one if they are equal).
  3. Keep each candidate offset that is consistent: going back to UTC with it and asking the offset there gives the same offset.
  4. One consistent offset → valid. Two → ambiguous; it picks the larger offset, which is the earlier moment (the first time 01:30 happens).
  5. None → the wall time is in a gap. Move forward 30 minutes and retry, up to 12 times. The status becomes gap and wallClock shows the shifted time actually used.
  6. If nothing works after 6 hours of steps, throw.

Source

export function resolveTeamWallClock(input: WallClockInput, zone: ZoneId): ResolvedWallClock {
  const wall = completeWallClock(input);
  let localMs = wallClockToLocalMs(wall);
  const before = offsetMsAt(zone, localMs - OFFSET_PROBE_MS);
  const after = offsetMsAt(zone, localMs + OFFSET_PROBE_MS);
  const candidates = before === after ? [before] : [before, after];

  for (let step = 0; step <= MAX_GAP_STEPS; step++) {
    const valid = candidates.filter((offset) => offsetMsAt(zone, localMs - offset) === offset);
    if (valid.length > 0) {
      const offset = Math.max(...valid);
      let status: WallClockStatus = 'valid';
      if (valid.length > 1) {
        status = 'ambiguous';
      } else if (step > 0) {
        status = 'gap';
      }
      return {
        utc: new Date(localMs - offset),
        status,
        wallClock: wallClockFromLocalMs(localMs),
        offsetMinutes: Math.round(offset / MS_PER_MINUTE),
      };
    }
    localMs += GAP_STEP_MS;
  }
  throw new RangeError(`No valid time found near ${JSON.stringify(wall)} in ${zone}`);
}
