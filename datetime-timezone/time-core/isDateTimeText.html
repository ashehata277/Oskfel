isDateTimeText()

True when the text has a date and a time joined by "T" (yyyy-MM-ddT…).

function isDateTimeText(value: string): boolean

Description

A cheap first check before handing text to new Date(). Every date-time the API sends has the letter T right after the 10-character date. A date-only value (2026-07-15), a time of day (08:00) or any other text fails it.

Why it exists

A quick, regex-free way to tell a date-time from a date-only value or other text.

  • new Date("2026-07-15") succeeds and returns UTC midnight, which is wrong for a date-only value; checking for the T first keeps date-only values out of the date-time path.

Without it: Date-only values could be read as UTC midnight instants and show as the previous day for users west of UTC.

Step by step

  1. Read the character at index 10 and compare it with "T".

Examples

These outputs were produced by running the real function.

isDateTimeText("2026-07-15T07:00:00Z")
true
isDateTimeText("2026-07-15")
false
isDateTimeText("2026-07-15 07:00:00Z")
false
isDateTimeText("08:00")
false

Good to know

  • Exported because Frontend from-api.ts uses it for its dev-mode warning about date-times sent without an offset.
