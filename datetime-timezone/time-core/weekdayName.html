weekdayName()

Weekday number (0 = Sunday) → localised name.

function weekdayName(weekday: number, style: 'long' | 'short', locale: string): string

Description

Used for the EEEE and EEE tokens. 7 January 2001 was a Sunday, so day 7 + weekday of January 2001 is always the right weekday. One formatter is cached per locale and style.

Why it exists

Weekday names must follow the user's language too.

  • The EEE and EEEE tokens need translated weekday names, taken from Intl and cached per locale.

Without it: A hard-coded English weekday list.

Step by step

  1. Build the cache key and fetch or create the formatter.
  2. Format Date.UTC(2001, 0, 7 + weekday).

Examples

These outputs were produced by running the real function.

weekdayName(0, "long", "en-GB")
"Sunday"
weekdayName(5, "short", "en-GB")
"Fri"

Good to know

  • Weekday numbers follow getUTCDay(): 0 Sunday … 6 Saturday.

Source

function weekdayName(weekday: number, style: 'long' | 'short', locale: string): string {
  const key = `${locale}|${style}`;
  let formatter = weekdayNameFormatters.get(key);
  if (!formatter) {
    formatter = new Intl.DateTimeFormat(locale, { weekday: style, timeZone: 'UTC' });
    weekdayNameFormatters.set(key, formatter);
  }
  return formatter.format(new Date(Date.UTC(2001, 0, 7 + weekday)));
}
