completeWallClock()

Fills missing time fields with 0 and refuses impossible dates like 30 February.

function completeWallClock(input: WallClockInput): WallClock

Description

Callers may pass just { year, month, day }. This function fills hour, minute, second and millisecond with 0. Then it checks the result is a real calendar moment: it packs the fields with Date.UTC and unpacks them again. Date.UTC silently rolls 30 February into 2 March, so if any field changed during the round trip, the input was impossible and the function throws.

Why it exists

Lets callers pass only a date, and rejects impossible dates instead of silently moving them.

  • Many callers only have a day (for example, midnight of a due date), so the time fields default to 0.
  • Date.UTC(2026, 1, 30) quietly becomes 2 March. Saving the wrong day without any error is worse than failing.

Without it: A typo like 30/02 would be saved as 2 March without anyone noticing.

Step by step

  1. Copy the fields, using ?? 0 for the optional time parts.
  2. Round-trip through wallClockToLocalMs and wallClockFromLocalMs.
  3. If any field differs, throw a RangeError; otherwise return the full wall clock.

Examples

These outputs were produced by running the real function.

completeWallClock({ year: 2026, month: 3, day: 5 })
{"year":2026,"month":3,"day":5,"hour":0,"minute":0,"second":0,"millisecond":0}

RangeError: Not a real wall clock: {"year":2026,"month":2,"day":3,"hour":25,"minute":0,"second":0,"millisecond":0}

Good to know

  • Catches 30 February, month 13, hour 25, minute 60, and similar.

Source

function completeWallClock(input: WallClockInput): WallClock {
  const wall: WallClock = {
    year: input.year,
    month: input.month,
    day: input.day,
    hour: input.hour ?? 0,
    minute: input.minute ?? 0,
    second: input.second ?? 0,
    millisecond: input.millisecond ?? 0,
  };
  const roundTrip = wallClockFromLocalMs(wallClockToLocalMs(wall));
  const fields = Object.keys(wall) as (keyof WallClock)[];
  if (fields.some((field) => roundTrip[field] !== wall[field])) {
    throw new RangeError(`Not a real wall clock: ${JSON.stringify(wall)}`);
  }
  return wall;
}
