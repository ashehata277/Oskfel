formatWallClock()

Prints a WallClock using a pattern like "dd/MM/yyyy HH:mm".

function formatWallClock(wall: WallClock, pattern: string, locale = 'en-GB'): string

Description

This is the single formatter used by every date shown on screen. It replaces each token in the pattern with the matching part of the wall clock. Text inside single quotes is copied literally, so 'at' prints "at". Because it formats fields that were already converted, no time zone is involved at this point.

Why it exists

One formatter for every date on screen, driven by the team's chosen format.

  • Each team picks its own date and time format (dd/MM/yyyy, MM/dd/yyyy, 12/24-hour). One pattern formatter applies it everywhere.
  • Angular's DatePipe works on a Date and applies its own zone; this formats fields that have already been converted, so no second conversion can happen.

Without it: Mixed DatePipe usages, each one able to convert the time zone a second time.

Step by step

  1. Work out the 12-hour hour (0 and 12 both become 12) and the weekday.
  2. Run FORMAT_TOKEN_PATTERN over the pattern; the longest tokens are listed first so MMMM wins over MM.
  3. Replace each token, keeping quoted literals as written.

Examples

These outputs were produced by running the real function. w = { year: 2026, month: 3, day: 5, hour: 14, minute: 7, second: 9, millisecond: 42 }

formatWallClock(w, "dd/MM/yyyy")
"05/03/2026"
formatWallClock(w, "EEEE, d MMMM yyyy")
"Thursday, 5 March 2026"
formatWallClock(w, "h:mm a")
"2:07 PM"
formatWallClock(w, "hh:mm:ss.SSS a")
"02:07:09.042 PM"
formatWallClock(w, "dd/MM/yyyy 'at' HH:mm")
"05/03/2026 at 14:07"
formatWallClock({ ...w, hour: 0 }, "h a")
"12 AM"

Good to know

  • Tokens: yyyy yy MMMM MMM MM M EEEE EEE dd d HH H hh h mm ss SSS a.
  • Letters that are not tokens pass through unchanged; quote any word that contains token letters.

Source

export function formatWallClock(wall: WallClock, pattern: string, locale = 'en-GB'): string {
  const hour12 = wall.hour % 12 === 0 ? 12 : wall.hour % 12;
  const weekday = new Date(Date.UTC(wall.year, wall.month - 1, wall.day)).getUTCDay();
  return pattern.replace(FORMAT_TOKEN_PATTERN, (token: string, literal: string | undefined) => {
    if (literal !== undefined) {
      return literal;
    }
    switch (token) {
      case 'yyyy':
        return pad(wall.year, 4);
      case 'yy':
        return pad(wall.year % 100, 2);
      case 'MMMM':
        return monthName(wall.month, 'long', locale);
      case 'MMM':
        return monthName(wall.month, 'short', locale);
      case 'MM':
        return pad(wall.month, 2);
      case 'M':
        return String(wall.month);
      case 'EEEE':
        return weekdayName(weekday, 'long', locale);
      case 'EEE':
        return weekdayName(weekday, 'short', locale);
      case 'dd':
        return pad(wall.day, 2);
      case 'd':
        return String(wall.day);
      case 'HH':
        return pad(wall.hour, 2);
      case 'H':
        return String(wall.hour);
      case 'hh':
        return pad(hour12, 2);
      case 'h':
        return String(hour12);
      case 'mm':
        return pad(wall.minute, 2);
      case 'ss':
        return pad(wall.second, 2);
      case 'SSS':
        return pad(wall.millisecond, 3);
      default:
        return wall.hour < 12 ? 'AM' : 'PM';
    }
  });
}
