offsetMinutesAt()

The zone's UTC offset in whole minutes at one moment.

function offsetMinutesAt(zone: ZoneId, instant: Instant): number

Description

The public, friendly version of offsetMsAt. It accepts any Instant and returns minutes, which is the unit people think in (+120, −300, +330). The Team Time Settings screen uses it to label each zone, for example "Africa/Cairo (UTC+2)".

Why it exists

The Team Time Settings dropdown labels each zone with its current UTC offset.

  • Admins pick zones from a long list, and "Asia/Kolkata (UTC+5:30)" is easier to recognise than the name alone.
  • Minutes are the unit people use for offsets, and the private offsetMsAt only works in milliseconds with raw numbers.

Without it: The settings screen would show bare zone names, or would need its own offset logic.

Step by step

  1. Convert the instant with toEpochMs.
  2. Get the offset with offsetMsAt.
  3. Divide by 60,000 and round.

Examples

These outputs were produced by running the real function.

offsetMinutesAt("Europe/London", "2026-01-15T10:00:00Z")
0
offsetMinutesAt("Europe/London", "2026-07-15T10:00:00Z")

offsetMinutesAt("America/New_York", "2026-01-15T10:00:00Z")

offsetMinutesAt("Asia/Kolkata", new Date("2026-01-15T10:00:00Z"))

Good to know

  • Pass the moment you care about: the same zone gives different answers in winter and summer.

Source

export function offsetMinutesAt(zone: ZoneId, instant: Instant): number {
  return Math.round(offsetMsAt(zone, toEpochMs(instant)) / MS_PER_MINUTE);
}
