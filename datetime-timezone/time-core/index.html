time-core.ts functions

One page for each of the 27 functions in Frontend/src/app/shared/time/core/time-core.ts: 16 exported and 11 private helpers.

How the file fits together

  • Engine (private): reads zone offsets from Intl and packs and unpacks wall clocks. Everything else is built on it.
  • Zones: UTC → team wall clock (utcToTeamWallClock) for display, and team wall clock → UTC (teamWallClockToUtc) for saving, with DST gaps and overlaps handled.
  • API strings: the UTC date-time strings exchanged with the API.
  • Calendar days: yyyy-MM-dd values that are never shifted by a zone.
  • Formatting: pattern-based text such as dd/MM/yyyy HH:mm.

HandoverApp and InspectionsApp have a smaller copy of this file (src/app/shared/time/time-core.ts), identical except that it does not have the functions marked "Frontend" below.
