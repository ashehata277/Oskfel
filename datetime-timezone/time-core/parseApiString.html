parseApiString()

API date-time string (with Z or an offset) → Date, or null.

function parseApiString(value: unknown): Date | null

Description

Reads a date-time sent by the backend. The backend always sends UTC with a Z, so the browser's own new Date() reads it correctly. A Date is a single moment; the device zone only matters if you print it with getHours(), which this code never does. The moment then goes to utcToTeamWallClock to be shown in the team zone.

Why it exists

Turns the backend's UTC text into a moment, refusing text that does not say which moment it is.

  • The backend guarantees UTC with a Z on every date-time (UtcDateTimeJsonConverter in all 13 services), so the browser's parser is enough; no regex is needed.
  • The two cheap checks in front of new Date() keep the one dangerous case out: a date-time with no Z.

Without it: API values would stay strings, or be parsed in many places with different rules.

Step by step

  1. A valid Date is copied and returned; an invalid one gives null.
  2. Anything that is not a string gives null.
  3. The text must be a date-time (isDateTimeText) and end with Z or an offset (endsWithUtcMarkerOrOffset); otherwise null.
  4. Parse with new Date(value) and return it, or null if the browser cannot read it.

Good to know

  • Text without Z or an offset is refused on purpose: new Date() would read it in the user's device zone and shift it.
  • Impossible dates such as 30 February roll forward (to 2 March) instead of failing. The backend never sends those, so this was accepted to avoid a hand-written parser.
  • .NET sends seven fractional digits; the browser keeps the first three.

Source

export function parseApiString(value: unknown): Date | null {
  if (value instanceof Date) {
    return Number.isFinite(value.getTime()) ? new Date(value.getTime()) : null;
  }
  if (typeof value !== 'string' || !isDateTimeText(value) || !endsWithUtcMarkerOrOffset(value)) {
    return null;
  }
  const instant = new Date(value);
  return Number.isFinite(instant.getTime()) ? instant : null;
}
