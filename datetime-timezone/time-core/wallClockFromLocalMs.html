wallClockFromLocalMs()

Unpacks a local-ms number back into a WallClock.

function wallClockFromLocalMs(localMs: number): WallClock

Description

The reverse of wallClockToLocalMs. It reads the number with the getUTC* getters so the browser's own time zone never gets involved. Whatever the laptop is set to, the result is the same.

Why it exists

Turns the packed number back into fields without the device zone leaking in.

  • After the offset maths the result has to be split back into year, month, day, and so on.
  • Reading with the getUTC* getters keeps the result identical on every machine, whatever zone the laptop is set to.

Without it: Using getHours() would make a user in Dubai see different team times from a user in London.

Step by step

  1. Make a Date from the number.
  2. Read year, month (+1), day, hour, minute, second and millisecond with the UTC getters.

Examples

These outputs were produced by running the real function.

wallClockFromLocalMs(1768478400000)
{"year":2026,"month":1,"day":15,"hour":12,"minute":0,"second":0,"millisecond":0}

Good to know

  • Never uses getHours() and friends, which would leak the device zone into the result.

Source

function wallClockFromLocalMs(localMs: number): WallClock {
  const date = new Date(localMs);
  return {
    year: date.getUTCFullYear(),
    month: date.getUTCMonth() + 1,
    day: date.getUTCDate(),
    hour: date.getUTCHours(),
    minute: date.getUTCMinutes(),
    second: date.getUTCSeconds(),
    millisecond: date.getUTCMilliseconds(),
  };
}
