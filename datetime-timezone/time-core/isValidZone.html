isValidZone()

True when the value is an IANA zone name the browser understands.

function isValidZone(zone: unknown): zone is ZoneId

Description

Team settings come from the server and may hold an empty string, null or a zone the browser has never heard of. Before any zone is used, callers ask this function. It is also a TypeScript type guard: after if (isValidZone(x)), x is typed as ZoneId.

Why it exists

Team settings may hold a missing or unknown zone; using it would crash.

  • The zone comes from the server, and older teams may have none, an empty string, or a name an older browser does not know.
  • Every place that picks a zone (settings normalisation, TeamTimeService.zoneOf, the team date pipe, the zone dropdown) checks first and falls back to the default.
  • As a TypeScript type guard it also narrows unknown to ZoneId.

Without it: A single bad zone value would throw a RangeError in every date on the page.

Step by step

  1. Reject anything that is not a non-empty string.
  2. Try to build a formatter with wallClockFormatter. If that throws, the zone is unknown.

Examples

These outputs were produced by running the real function.

Good to know

  • A successful check also warms the formatter cache, so the first real conversion is fast.

Source

export function isValidZone(zone: unknown): zone is ZoneId {
  if (typeof zone !== 'string' || zone.length === 0) {
    return false;
  }
  try {
    wallClockFormatter(zone);
    return true;
  } catch {
    return false;
  }
}
